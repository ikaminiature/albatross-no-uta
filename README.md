# アルバトロスの詩 — 航行試験

依存ライブラリ不要の2D航行試作。複数船を一人で操作します。対戦用のオンライン機能はありません。試遊ページには noindex を指定しています。

## iPadで試す

GitHub Pagesの試遊ページをSafariで開き、「ゲーム開始」をタップします。

## ローカルで試す

1. このブランチのファイルを、iPadと同じWi-FiにつながったPCへ取得します。
2. このフォルダで `python3 -m http.server 8000 --bind 0.0.0.0`（または `npm start`）を実行します。
3. iPadのSafariで `http://PCのLAN内IPアドレス:8000` を開きます。PCのファイアウォールでは必要に応じてプライベートネットワークの8000番だけ許可してください。
4. ゲーム開始 → 自動で風向き判定 → 速力 → 回頭・実行の順にタップします。境界では寄せる側を選択します。船の追加はターン開始前にできます。

PCのIPはmacOSのネットワーク設定やWindowsの `ipconfig` で確認できます。クラウドのlocalhostにはiPadから直接アクセスできません。試遊後はPC側で Ctrl+C を押して終了します。

## 開発・検証

- Node.js 18以上で `npm test`：風の上限、境界、速度選択、行動順、直進のルールテスト。
- `npm start` はPython 3が必要です。ビルドや依存関係のインストールは不要。
- HTML・CSS・JavaScriptの静的ファイルなので、編集後にSafariを再読み込みします。

## 試作上の取り決め

- 海図は横60×縦80cm相当。1cmあたり24×24のSVG座標で、盤面は1440×1920。速力1の移動は24単位。船は幅24×長さ48。画面上では全体を縮小表示します。
- 風の角度と風見鶏の矢先は「来る方角」。開始前は北風で、毎ターン開始時にd6を1回振り、直前の方角から1・2は時計回り90°、3・4は180°、5・6は270°回します。
- 行動順はターン開始時の位置を風上方向へ射影して決定。同位置は船番号順。
- 上限は行動開始時だけ判定。回頭中は再判定しません。
- 境界の記録は船首を時計回り／反時計回りへ微小に寄せたものとして適用し、風向き変更時も保持。45°・135°・225°・315°で回頭を終えると選択が必要です。回頭しない場合は記録を保持します。
- スキルテストは手動判定。失敗時は速力0で通常の回頭2回。成功時は現在速度から±1または維持（0〜3）。
- 行動開始時から停帆を維持する場合は、1回の自由回頭で行動終了します。
- 海図の範囲は固定。端の移動制限、座礁、船の衝突は未実装です。

## ドット絵を足すとき

1cmタイルは24×24pxで作り、`app.js` の `seaTiles` に `{col: 0, row: 0, src: "./tiles/example.png"}` の形で追加します。列・行は左上を0として、海図の `sea-art` レイヤーに配置されます。レイヤーはグリッドと船の下にあり、画像はピクセルをぼかさず表示します。
